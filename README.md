
# Симуляция 2D мира


## Описание:
Симуляция представляет карту в виде матрицы NxM с разбросанными на ней статическими объектами (деревья, трава, камни, яблоки) и живыми существами (волки, кролики).

Главная мотивация существа — поиск еды для утоления голода, который уменьшается каждый N-й ход, когда голод достигает 0, существо умирает

Соответственно: кролики ищут яблоки, волки - кроликов

Поиск кратчайшего пути к еде реализован с помощью простого алгоритма BFS.
