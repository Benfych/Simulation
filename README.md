# Simulation — 2D симуляция мира

Консольная пошаговая симуляция 2D-мира

## Описание

Симуляция представляет карту в виде матрицы **N×M**, на которой разбросаны:

- **Статические объекты** — деревья, камни, яблоки
- **Живые существа** — волки, кролики

Главная мотивация существ — поиск еды для утоления голода, который уменьшается каждый N-й ход. Когда голод достигает 0, существо умирает.

- 🐰 Кролики ищут 🍎 яблоки
- 🐺 Волки ищут 🐰 кроликов

При встрече волка и кролика происходит бой: волк атакует кролика, отнимая у него HP. Когда HP падает до 0, существо умирает.

Поиск кратчайшего пути к еде реализован с помощью алгоритма **BFS** (поиск в ширину).
