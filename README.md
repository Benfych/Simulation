
# Симуляция 2D мира

## Описание:
Симуляция представляет карту в виде матрицы NxM с разбросанными на ней статическими объектами (деревья, камни, яблоки) и живыми существами (волки, кролики).

Главная мотивация существа - поиск еды для утоления голода, который уменьшается каждый N-й ход. Когда голод достигает 0, существо умирает

Соответственно: кролики ищут яблоки, волки - кроликов

Поиск кратчайшего пути к еде реализован с помощью алгоритма BFS.

## Конфигурация
В файле cfg/config можно настраивать мир под себя

```bash id="r2"
# ------------------Карта-----------------------
# Карта(высота, ширина, алгоритм поика пути)
MAP_DEFAULT_CONFIG = Map_cfg(20, 20, BFS)
# ----------------------------------------------

# ------------------МОБЫ-----------------------
# Существо (количество на карте, цель поиска, скорость передвижения, количество здоровья)
PREDATOR_DEFAULT_CONFIG = Predator_cfg(5, (Herbivore), 1, 100)
HERBIVORE_DEFAULT_CONFIG = Herbivore_cfg(5, (Apple), 1, 100)
# -----------------------------------------------

# ------------Статические объекты----------------
# Существо (количество на карте)
APPLE_DEFAULT_CONFIG = Apple_cfg(5)
TREE_DEFAULT_CONFIG = Tree_cfg(10)
ROCK_DEFAULT_CONFIG = Rock_cfg(5)
# ------------------------------------------------
```

## Запуск

```bash id="r2"
py main.py
```
